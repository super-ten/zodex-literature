# 检索、访问、筛选与归档

## 访问与范围

默认正式平台为CNKI、Web of Science、ScienceDirect、Springer Nature Link、高教社Frontiers（journal.hep.com.cn）。后者不是frontiersin.org。默认五平台来自用户文档；用户明确扩展时可增加平台，并记录修订。公开网页定位与开放补检单独记录，不冒充数据库内部检索。

优先读取当前用户桌面“CARSI访问入口.html”；缺失或失效时查询厦门理工学院图书馆官方入口。文件只是链接索引。分别验证入口、机构认证、检索、全文获取；记录VPN/代理/已有会话是否可确认，未知就写未知。已存在机构会话不证明独立CARSI成功。复用正常登录或浏览器已保存凭据；无凭据请用户在官方页面登录，不猜默认密码，不绕过验证码。

核实WoS实际可用索引和年代。AHCI缺失是当前检索覆盖限制，不等于全文不可获取。期刊当前AHCI身份与论文发表年份的论文级收录分别记录；官方Master Journal List用于期刊核验，不能把当前期刊收录标签倒推至所有历史论文。

扩展检索授权存在时，按需使用OpenAlex/Crossref定位元数据、出版社官网、Project MUSE/JSTOR/OpenEdition及机构知识库取得可用全文。CASHL作为待申请文献传递渠道，提交申请或产生费用前依用户授权执行。开源工具不赋予订阅权限；工具可用性和额度现场查证，不默认已安装。开放全文接口的同源结果不算独立证据。

官方核验入口：https://mjl.clarivate.com/ 、https://help.openalex.org/ 、https://www.crossref.org/documentation/retrieve-metadata/rest-api/ 。只在需要对应能力时查阅。

## 概念组扩展与引文追溯

1. 拆解研究问题，为每个概念整理中英文同义词、邻近概念及历史表达，说明差别。示例：具身组embodiment / embodied cognition / embodied experience / corporeality / sensorimotor；文化组cultural heritage / cultural memory / ritual / intangible cultural heritage；叙事组narrative / storytelling / multimodal narrative / digital storytelling。它们是检索入口，不是全部同义词；区分人的身体经验、具身认知和具身智能。
2. 先用两组交叉扩大理论发现，再做多组交集提高直接相关性；组内OR、组间AND，按平台适配字段、短语与截词。福建、福文化、智能媒体等作为情境检索，不在所有表达中强制加入。记录词表变更理由，控制主题漂移。
3. 种子文献按概念解释力、方法适用性、证据质量或争议价值筛选。高被引和索引身份不能代替内容判断。保留反例与不同立场。
4. 向后追溯概念来源，向前查验证、批评和修正；对高相关作者、期刊及新术语定向补检，关键期刊补查官网目录。引文追溯导入的新文献同样筛选和去重。
5. 检查概念组合、语言、年代、理论传统覆盖及连续补检新增价值。根据实际结果说明停止理由和盲区，不按固定篇数宣布充分，也不以未检出证明无人研究。

## 筛选标准

标题摘要初筛、全文复筛分开。状态为核心纳入、理论与背景、待全文确认、排除；每次决策保存理由和依据。全文缺失不是质量差。

理论论文检查概念一致性、推理及反驳处理；量化研究检查设计、测量、分析及结论强度；质性研究检查材料来源、解释过程、情境和反例；设计案例检查过程证据、评价方法与可迁移边界；综述检查检索范围和综合方法。不能因哲学论文无样本或解释性研究无实验就判低质。

保留必要专著、书章及地方材料作为理论与背景，标注用途，不能自动标为AHCI。排除同词异义、无关及重复版本；不同版本保留关系，勿混用页码。

## Zotero写入验收

规范化DOI（去网址前缀、统一大小写）优先去重；无DOI比对题名、作者、年份，模糊匹配须核对，不能自动合并不同论文。已存在条目加入本批分类，避免重复创建；保存来源与筛选理由。

保存元数据和合法全文，允许完整HTML快照作为全文；单独注明作者稿/出版版、PDF/HTML、解析/OCR状态。检查文件真实格式、目标题名、完整性和可读性，PDF链接不是PDF附件。图像关键证据需实际视觉检查。

每次写入后读回collection key、item key、附件或笔记，核对父子关系。写请求响应不明时先查询是否成功，再重试，避免重复。无法创建分类或导入附件就列待办，保持本地待导入产物。
